# Project Workflow

## Versioning & Deployment
For every change made to the codebase:
1. **Increment Version:** Update the version number in the `VERSION` file (e.g., from `1.0.1` to `1.0.2`).
2. **Commit:** Stage your changes, including the updated `VERSION` file, and commit.
3. **Push:** Push the changes to the remote repository.
