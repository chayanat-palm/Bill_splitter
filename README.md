# Bill Splitter

A modern, fast, and easy-to-use tool to split bills accurately. Built for convenience and quick sharing.

## Features
- **Easy Split:** Input prices and split effortlessly.
- **Tax/Service:** Supports VAT 7% and Service Charge 10% toggle.
- **Copy Summary:** Quickly copy the total split or individual amounts for easy sharing via LINE or other apps.
- **Visual Feedback:** Instant visual feedback when copying amounts.

## How to use
1. Open the app.
2. Toggle SVC or VAT if required.
3. Add your items (Name and Price).
4. Enter any extra fees or total discounts.
5. Copy the summary or individual amounts and send them to your group.

## Deployment
This app is hosted via GitHub Pages from the `/docs` folder.
